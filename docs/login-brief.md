# Login

Modo: Operate. Objetivo: probar visualmente y funcionalmente un login sin datos reales.

Composición: panel de identidad y ejemplo de documento en escritorio; formulario de acceso y credenciales dummy siempre visibles, también en móvil. Dirección elegida para esta primera entrega: archivo contemporáneo sobrio, tipografía clara y verde bosque. Marca provisional editable.

Estados: vacío, validación, contraseña visible/oculta, espera, error y recuperación informativa. Tras éxito navega al dashboard; persiste solo identidad demo en sessionStorage, nunca contraseña. Diseño visual original conservado.
